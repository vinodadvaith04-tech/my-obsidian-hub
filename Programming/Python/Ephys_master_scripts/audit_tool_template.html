How this works

Every window shows the same 3 s trace twice: miniML (top, markers M1…) and the second detector (bottom, O1…). Markers are real by default. You only touch what is wrong.

Click a markermark it as false (grey cross). Click again to undo.
Shift+click a markermark it as unsure (amber ?). Excluded from precision/recall and from the truth list.
Click an empty spot on the traceadd a missed event. It snaps to the nearest peak (within about 8 ms) and takes its direction from the sign of that peak (or the direction you force in the drop-down). Click the green diamond again to remove it.
Two markers on one eventmark the extra one false (a double detection is not a second event). Otherwise the other detector is counted as having missed a "second" event.
Event only one detector foundyou do not click it: if the other panel's marker is real, the detector without a marker is counted as having missed it (green ring). Clicking a spot that the other detector already marked just tells you so.
Space / Enterwindow finished ("all fine" is a valid result: no clicks, then Space). Only finished windows are exported as audited.
Sskip an unusable window (writes "skip" into the note).
← → / Jprevious / next window, J = next window not done yet.
Z / Backspaceundo the last click in this window.
wheel, drag, 0, Yzoom time around the cursor, pan, reset view, fit the y-axis to what is on screen.
A U Dclick direction: auto / up / down.

Saving. Progress is saved in this browser automatically after every click. It is only kept for this browser and this file location, so press Export clicks at the end of each session (and every so often) and keep the JSON. Import JSON restores it, also on another computer. Then run import_audit_clicks.py to copy the result into audit_labels.xlsx.

Two markers closer than ms count as the same event. Traces: 3 kHz low-pass, slow baseline removed, same as page_XX.png.
